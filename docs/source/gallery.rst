Gallery
=======

Every example in the ``examples`` directory, with the figure it draws and its
code. Each one is a function that saves a ``.gle`` script to the current
directory; ``examples/run_and_compile.py`` runs them all and compiles the
figures shown here into ``examples/outputs/`` (GLE required):

.. code-block:: bash

   python examples/run_and_compile.py
